Purim Myfolio API

Public read-only API สำหรับข้อมูล Portfolio — รองรับ CORS จากทุก Origin

https://<your-username>.github.io/<repo>/api

Endpoints

GET /projects.json
รายการโปรเจกต์ทั้งหมด พร้อม id, title, desc, tags, gallery, year
↗ ดูข้อมูล
GET /profile.json
ข้อมูลส่วนตัว ทักษะ และช่องทางติดต่อ
↗ ดูข้อมูล
GET /tags.json
รายการ tag ทั้งหมดที่ใช้ในโปรเจกต์ (เรียงตัวอักษร)
↗ ดูข้อมูล
วิธีใช้งาน (JavaScript)

const BASE = "https://<your-username>.github.io/<repo>/api";

// ดึงโปรเจกต์ทั้งหมด
const projects = await fetch(`${BASE}/projects.json`).then(r => r.json());

// ดึงโปรเจกต์ id เดียว
const project = projects.find(p => p.id === 0);

// กรองตาม tag
const flutter = projects.filter(p => p.tags.includes("Flutter"));

CORS: GitHub Pages ตั้งค่า Access-Control-Allow-Origin: * ให้อัตโนมัติ — ไม่ต้องตั้งค่าเพิ่มเติม
